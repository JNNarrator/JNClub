# JNClub 功能规划 · 2026-13（Dashboard 2.0 · Actionable Dashboard）

> 状态：✅ 已完成（后端 alerts + 前端 Dashboard 2.0 已实施，构建验证通过）
> 前置：2026-12 概览页基础优化已完成。
> 目标：把概览页从「数据展示」升级为「今日必办 + 可操作入口」，让用户回到首页时能立刻知道要做什么、点哪里处理。
> 关键设计：不引入图表库，不新增业务表；只新增 `/api/stats/summary` 的 `alerts` 字段与前端偏好 `dash.density`。

---

## 一、现状与问题

1. 概览页已有统计、趋势、磁盘、密码库健康、最近动态、快捷入口，但「信息展示多、行动指引少」。
2. 最近收藏 / 便签 / 文件只有展示，点击后没有直接动作，需要再进入模块找。
3. 趋势图固定近 6 个月，缺少时间范围切换、悬浮明细和图例筛选。
4. 布局编辑器支持排序/隐藏，但没有「今日必办」分区，也没有显示密度偏好。
5. 空态、卡片间距等细节已由 2026-12 优化，本版继续收敛视觉层级。

---

## 二、功能规划

### 1. 今日必办 TodayPanel（后端 alerts + 前端提醒卡）

- **后端**：`StatsService.summary()` 新增 `alerts` 数组，按优先级聚合：
  - `todo`：今日到期 / 已逾期待办 → `/todos`，逾期时为 `danger`，否则 `warning`
  - `recycle`：回收站非空 → `/recycle`，`warning`
  - `vault`：密码库存在重复密码 → `/?module=vault`，`danger`
  - `readLater`：稍后读未读 > 0 → `/?module=bookmarks`，`info`
- Alert 结构：
  ```json
  {
    "type": "todo",
    "level": "danger" | "warning" | "info",
    "title": "今日待办",
    "desc": "2 件今天到期，1 件已逾期",
    "count": 3,
    "action": "/todos"
  }
  ```
- **前端**：新增「今日必办」区块，默认放在问候卡片之后；提醒卡支持点击跳转、数量徽标、等级色条；无提醒时显示统一空态。
- 布局编辑器中该区块名称为「今日必办」，可排序、可隐藏。

### 2. 最近动态可操作化

- 最近收藏：点击直接新窗口打开 URL；无 URL 时回到收藏模块。
- 最近便签：点击进入便签编辑页 `/notes/{id}`。
- 最近文件：点击直接下载 `/api/clouddisk/files/{id}/download`。
- 继续阅读保持原有「站内阅读 / 进度回写」。
- 列表项 hover 时显示品牌色箭头，移动端常显箭头提示可点击。

### 3. 趋势增强

- 时间范围切换：近 3 / 6 / 12 个月，切换后重新请求 `/api/stats/trend?months=`.
- 图例筛选：点击图例可隐藏/恢复对应系列，柱状图与最大值刻度只统计可见系列。
- Hover 明细：鼠标悬停某个月份柱组时显示浮层，列出该月各可见系列数值；非当前柱组弱化。
- 保留原自绘柱状图，不引入图表库。

### 4. 布局编辑器 2.0

- 新增「今日必办」分区。
- 新增「显示密度」偏好：
  - `comfortable`（舒适，默认）
  - `compact`（紧凑）
  - 持久化 Key：`dash.density`，随 `dash.order` / `dash.hidden` 一起保存到用户偏好。
- 恢复默认会同时重置顺序、隐藏项和密度。

### 5. 视觉打磨

- 紧凑统计卡已在 2026-12 完成，本版继续统一面板间距。
- 所有面板空态统一为轻量虚线框 `panel-empty`；今日必办空态独立轻提示。
- 紧凑密度下自动收窄 `.dash` 间距、面板 padding、趋势图高度等。
- 全局 `prefers-reduced-motion` 已存在，不新增大动画。
