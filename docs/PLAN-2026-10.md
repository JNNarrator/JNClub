## 规划背景

2026-09 已完成并部署：分享增强、稍后读+阅读进度、日历视图、网页快照、RSS 阅读器。当前项目已有不错的 UI 地基：

- 设计 Token 体系：`themes/tokens.ts`（颜色/阴影/圆角/玻璃拟态/动效缓动）
- 玻璃拟态全局覆盖：`assets/main.css`（modal/drawer/popover 统一毛玻璃）
- 动画适配层：`shared/components/animation/`（JCountUp / JShinyText / JMagnet / JAnimatedContent 等）
- 已有路由过渡、卡片交错入场、拖拽回弹、FPS 看门狗降级、`prefers-reduced-motion`

但实际落地仍存在明显不一致，规划前核实到的问题：

1. **样式硬编码仍分散**：Dashboard / Todo / Calendar / Feeds / PasswordEditor / DeadLinkModal 等大量直接使用 `#ff8a97`、`#f0a13a`、`rgba(...)`、固定圆角/阴影，未走 Token。后续换主题或统一风格需要逐文件改。
2. **Home.vue 已超 1500 行**：顶栏、目录树、模块工具栏、筛选条、批量操作条、多个弹窗全部堆在一个文件；新增功能容易互相影响。
3. **动画组件使用面太窄**：J* 动画目前主要出现在 Welcome 和 SearchDrawer；业务卡片/列表/数字统计/弹窗没有统一应用，各组件各写各的 hover/enter。
4. **加载态体验单一**：主要依赖整块 `NSpin` 转圈；缺少骨架屏、局部 loading、错误重试态。
5. **响应式还有缺口**：移动端目录靠抽屉，但底部 Tab 只有 6 项，日历/订阅/音乐等路由页入口依赖侧栏；网格列数、间距、卡片密度未完全自适应。
6. **性能仍有优化空间**：大列表渲染、drag ghost、大面积渐变/backdrop-filter、resize 监听等可再收敛。

## 方向一：UI 重构 — Token 收敛与组件化

### ① 设计 Token 收敛

**目标**：业务组件不再出现魔法色值/固定圆角/阴影，全部走 `tokens.ts` 或语义 class。

- 扩展 `DesignTokens`：
  - 模块色：`bookmarkColor / noteColor / fileColor / vaultColor`（替换 Dashboard 里的 `#7c5cff / #2f9df7 / #0fbf8c / #f0a13a`）
  - 危险/警告/成功语义色补齐：`danger / dangerSoft / warningText / successText / dangerText`（替换 `#ef5b6b / #ff8a97 / #f0a13a / #37c978` 等）
  - 状态徽标色、星标色、快照色、拖拽阴影等按需补充
- 清理范围：
  - `DashboardView.vue`、`TodoView.vue`、`CalendarView.vue`、`FeedsView.vue`
  - `PasswordEditorModal.vue`、`DeadLinkModal.vue`、`NoteVersionsModal.vue`、`RecycleView.vue`
  - `CollectionCard.vue`、`ReadingModal.vue`、`DiskView.vue`、`EmptyState.vue`
- 输出：grep 校验 `jnclub-web/src` 下业务组件不再出现非注释的 hex/rgba 字面量（动画/粒子/第三方预览色除外）。

### ② 共享 UI 基件

**目标**：把重复出现的结构抽成少量共享组件，后续新页面直接拼装。

新增 `shared/components/ui/`：

- `JPageHeader.vue`：统一页面标题、面包屑、右侧通用操作区
- `JModuleToolbar.vue`：统一「新建/导出/归档/检测」等模块按钮组布局
- `JFilterBar.vue`：统一目录 chip / 标签 chip / 状态筛选条
- `JSkeletonGrid.vue` / `JSkeletonList.vue`：骨架屏占位
- `JEmptyState.vue`：把现有 `EmptyState.vue` 升级为全局统一空态（图标/文案/CTA/重试）
- `JStatCard.vue`：概览统计卡片基座（数字 + 图标 + 趋势 + hover 动效）
- `JBatchBar.vue`：收藏/便签批量操作条

复用原则：优先把现有组件内部样式上提，不强行重写全部页面；新页面默认使用基件。

### ③ Home.vue 拆件

**目标**：把 1500+ 行主页面拆成职责单一的组件，逻辑不变。

- `shared/layout/AppHeader.vue`：顶栏（面包屑、搜索、多选、视图切换、刷新、主题、用户）
- `modules/bookmark/components/ModuleToolbar.vue`：模块内工具栏（新建收藏/便签、导出、归档、失效检测、上传）
- `modules/bookmark/components/TagFilterBar.vue`：标签筛选条
- `modules/bookmark/components/BatchBar.vue`：批量操作条
- 弹窗保持独立文件，`Home.vue` 只负责编排与数据流
- 顺带把 `OverviewLayout / TodoLayout / CalendarLayout / FeedsLayout / RecycleLayout` 中重复的面包屑/标题/工具栏结构逐步切到 `JPageHeader`

## 方向二：动画优化 — 统一节奏与交互反馈

### ④ 动效 Token 与全局规范

- 在 `animation/tokens.ts` 增加：
  - `enterDuration / leaveDuration / hoverDuration`
  - `enterDistance / staggerBase`
  - 语义动效：`cardIn / listIn / modalIn / drawerIn / routeIn`
- 形成 `motion` 使用规范：业务侧只使用 J* 组件或全局 class，不直接写零散 `transition: all .3s`。
- 统一现有全局 class：`jnclub-bouncy / jnclub-ease / fade-in-up-stagger` 与 Naive 内置动画的关系。

### ⑤ 页面与容器过渡

- 路由过渡升级：当前 `page-fade` 仅淡入+位移；改为更克制的「页面淡入 + 内容轻微上移 + 透明度」，保持 Apple 风格，不引入夸张缩放。
- 模块切换/视图切换过渡：沿用现有 `module-fade`，统一时长与缓动。
- 弹窗/抽屉/下拉：统一玻璃层入场（scale 0.98 → 1 + fade），与 Naive 默认动画叠加，注意不要破坏可访问性。

### ⑥ 卡片/列表/统计微交互

- 收藏/便签卡片：统一 hover lift（`translateY(-2px)` + 阴影加深 + favicon/图标轻微放大），active 按压缩放。
- 列表行：hover 背景 + 左侧品牌条渐入；批量勾选时打勾图标回弹。
- 概览看板：统计数字用 `JCountUp` 入场滚动；卡片 stagger 入场；健康分/进度条加宽带动画。
- 拖拽排序：保留 `drop-settle`，补齐 drag ghost 的 scale/透明度过渡，减少拖拽时重排闪烁。
- 导航/底部 Tab：active 指示条使用布局动画（`FLIP` 或 CSS 过渡）平滑滑动，而不是仅变色。

### ⑦ 性能与可访问性约束

- 动画只使用 `transform / opacity / filter`，避免布局属性。
- 继续遵守 `prefers-reduced-motion`：全局关闭非必要动画。
- 继续遵守 FPS 看门狗：`data-perf-tier="2"` 时关闭连续流光/渐变动画，保留一次性入场。
- 大列表 hover 动效避免逐帧 `mousemove`；已有 JMagnet 不用于卡片列表。
- 动画组件只按需 import，避免全局引入造成包体膨胀。

## 方向三：加载、空态与响应式

### ⑧ 骨架屏与局部加载

- 收藏/便签/云盘/密码库首次加载：用 `JSkeletonGrid/List` 替代整块 `NSpin`。
- 概览/日历/订阅/待办：数据加载时显示对应骨架布局。
- 局部操作（刷新、创建、删除、排序）：保留按钮 loading / 行级 loading，不让整个内容区转圈。
- 错误态：请求失败显示统一错误占位 + 「重试」按钮，而不是一直空列表。

### ⑨ 响应式完善

- 桌面：内容区设置合理最大宽度（如 1400px）并居中；网格用 `repeat(auto-fill, minmax(...))` 自适应列数。
- 平板/移动：
  - 收藏/便签卡片 2 列 → 1 列；列表行压缩元信息。
  - 顶部工具栏允许横向滚动或收纳到「更多」。
  - 底部 Tab 支持 7+ 项（或「更多」抽屉），让日历/订阅等路由页在移动端也有入口。
  - 目录抽屉、批量操作条、FAB 的 safe-area 与键盘弹起处理。
- 主题：检查亮/暗模式下玻璃透明度、对比度、滚动条、选中态。
