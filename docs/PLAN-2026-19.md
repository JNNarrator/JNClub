## 二、M1 · 质量地基（可量化达标）

### M1-1 token 从 JS 注入改为 CSS 声明（修 FOUC + 建立主题钩子）

**问题**：P1-3。token 在 `App.vue` onMounted 后才写入 `:root`，首帧全部回退；且无 `html.dark` / `data-theme` / 暗色媒体查询，硬编码颜色**永不随主题变化**。

**做法**：

1. 新增构建期生成：`jnclub-web/scripts/gen-theme-css.mjs`，从 `jnclub-web/src/themes/tokens.ts` 的 `lightTokens` / `darkTokens` 经 `tokensToCSSVars()` 生成 `jnclub-web/src/themes/tokens.generated.css`：
   - `:root { …lightTokens 全量… }`
   - `:root[data-theme='dark'] { …darkTokens 全量… }`
   - 兜底 `@media (prefers-color-scheme: dark) { :root:not([data-theme]) { …dark… } }`
   - `package.json` 的 `dev` / `build` 前置该脚本（`predev` / `prebuild`），生成物加入 `.gitignore` 或入库二者择一（建议入库，便于代码审查 diff）。
2. `jnclub-web/src/main.ts` 在 `import './assets/main.css'` **之前** `import './themes/tokens.generated.css'`，保证 CSS 在 head 同步生效。
3. `jnclub-web/index.html` head 内联**最小首屏快照**（`--bg-page`/`--bg-card`/`--text-1`/`--text-2`/`--text-3`/`--brand`/`--border`/`--radius-sm`/`--dur`）+ 一段预判脚本读 `localStorage.theme` 写 `document.documentElement.dataset.theme`，覆盖「CSS 尚未加载」与「主题未判定」两个窗口。
4. `jnclub-web/src/App.vue` 保留 `isDark` 与 naive-ui `theme` / `themeOverrides` 切换，但删除 `applyTokens()` 的 126 次 `setProperty`，改为只写 `data-theme`；`matchMedia` 监听同步改为写 `data-theme`。
5. `jnclub-web/index.html:9` `theme-color` 增加暗色分支（`media="(prefers-color-scheme: dark)"`），并由 `data-theme` 变化时 JS 更新。

**验收**：冷启动（清缓存 + 硬刷新）首帧截图无「无样式闪烁」；`DOMContentLoaded` 时 `getComputedStyle(document.documentElement).getPropertyValue('--bg-page')` 已为有效值；切换主题后 `<html data-theme>` 正确变化且无需刷新。

## 三、M2 · 观感提升（可感知）

### M2-1 弹层与过渡手感统一

**问题**：P2-1。

**做法**：

1. `jnclub-web/src/themes/light.ts` / `dark.ts` 补齐 naive-ui 段：`Modal` / `Drawer` / `Popover` / `Dropdown` / `Message` / `Notification` / `Tooltip` / `Dialog`，值全部取自 `tokens.ts`（圆角、阴影、颜色、边框），不再让弹层沿用 naive 默认。
2. `jnclub-web/src/assets/main.css` 覆盖弹层过渡曲线：`.n-modal` / `.n-drawer` / `.n-popover` / `.n-dropdown` 的 `transition-duration: var(--dur)` + `transition-timing-function: var(--ease)`；抽屉用 `--ease`、气泡用 `--ease-bouncy`。
3. 路由过渡 `page-fade`（`App.vue:144-155`）当前 out-in 双段各 0.2s ≈ 400ms → 收敛到 `--dur-fast`（0.15s），与弹层节奏对齐。
4. `SideNav.vue:262` `transition: all .18s ease` → `var(--dur-fast) var(--ease)`。

**验收**：任意弹窗 / 抽屉 / 气泡的开合曲线与全站一致；无 naive 默认 Material 曲线残留。

### M2-2 主题切换过渡（View Transition）

**问题**：P2-2。主题切换整页硬闪，全项目 0 处 `startViewTransition`。

**做法**：`App.vue` 的 `toggleTheme()` 用 `document.startViewTransition()` 包裹（feature detect + `prefers-reduced-motion` 判断），CSS 增加：

```css
::view-transition-old(root), ::view-transition-new(root) { animation: none; mix-blend-mode: normal; }
::view-transition-new(root) { animation: jnclub-theme-reveal 0.4s var(--ease); }
@keyframes jnclub-theme-reveal {
  from { clip-path: circle(0% at var(--vt-x, 50%) var(--vt-y, 50%)); }
  to   { clip-path: circle(150% at var(--vt-x, 50%) var(--vt-y, 50%)); }
}
```

`--vt-x` / `--vt-y` 由切换按钮的 `getBoundingClientRect()` 写入。不支持的浏览器降级为现有行为。

**验收**：桌面 Chrome / Safari 切换主题为从按钮扩散的圆形揭示；`prefers-reduced-motion` 下直接切换无动画。

### M2-3 动效时长与曲线收敛

**问题**：P2-3 + P2-4。

**做法**：

1. token 扩充：`--dur-fast` 0.15s、`--dur` 0.2s、`--dur-slow` 0.3s、`--dur-slower` 0.5s，替代当前 22 种字面量中的绝大多数（长动画如 2.8s / 6s 保留但改为命名 token 并注明用途）。
2. 裸 `ease`（20 处）/ `linear`（6 处）/ `ease-in-out`（5 处）替换为 `var(--ease)` / `var(--ease-bouncy)`。

## 七、风险与边界

| 风险 | 说明 | 缓解 |
| --- | --- | --- |
| 对比度调整改变观感 | `--text-3` 提深（#8E8E93 → #6E6E73）、品牌渐变压深（末端 #FF8FAB → #C0407A）会明显改变亮色观感 | 实施后出一轮亮色全页截图对照再定稿；若压深不可接受，备选方案为「主按钮改深字」（深字 on 亮粉底可达 7.83:1） |
| token 机制主干改动 | M1-1 把 126 个变量从 JS 注入改为 CSS 声明，牵动主题切换与 naive-ui overrides | 单一数据源仍是 `tokens.ts`，CSS 由脚本生成；naive-ui overrides 继续读同一份 token，保证两者不漂移 |
| 音乐前端折中边界被侵蚀 | 若统一过程中顺手改了品牌色 / 字体，会破坏其独立气质 | 明确写入边界：**品牌色、字体、色温三项不动**；只统一几何、动效、主题透传 |
| 结构债清理范围失控 | 21 处反向依赖全拆会引入大范围改动 | 只处理明确不合理的（EmptyState 上移、类型上移）；路由聚合类依赖记录豁免；不做目录级重构 |
| 车机模式 px→rem 迁移 | 全量迁移风险高 | 本轮不做全量迁移，改为显式覆盖关键字号与点击区 |
| 专辑封面 | 依赖后端是否有封面字段 | 无字段则本轮不做，记录为后续依赖 |

**明确不做**：不改后端接口与数据模型；不做音乐前端品牌色 / 字体替换；不做大规模目录重构；不引入新的 UI 组件库。

## 九、验收标准

| 维度 | 指标 | 目标 |
