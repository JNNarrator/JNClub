# JNClub 功能规划 · 2026-12（概览界面样式优化）

> 状态：✅ 已完成（概览页基础优化已实施并合入，含顶部操作收敛、分组、紧凑统计卡、4 栏最近动态、统一空态等）
> 范围：仅 `DashboardView.vue` / `OverviewLayout.vue` / 相关共享 UI 基件，纯前端视觉与信息架构治理。
> 目标：解决当前概览页「拥挤、混乱、视觉层次弱」的问题，让概览页成为清晰的数据工作台。
> 后续：Dashboard 2.0（今日必办 / 可操作最近动态 / 趋势增强 / 布局 2.0）见 [PLAN-2026-13.md](./PLAN-2026-13.md)。

## 一、现状问题（基于当前代码核实）

### 1. 顶部信息重复，操作入口过多
- 外层 `JPageHeader` 已有「概览 / 数据看板与快捷入口 / 返回 / 主题」。
- 内部 `DashboardView` 又渲染一行「数据概览 + 布局 / 全量备份 / 数据导出 / 数据导入 / 查重 / 刷新」。
- 两行标题和按钮叠加，第一屏视觉噪音大。

### 2. 区块过多且缺少分组
- 默认依次展示：问候 → 统计卡片 → 今日待办 → 数据趋势 → 云盘占用+密码库健康 → 最近动态（4 个面板）→ 快捷入口。
- 所有区块都是同等玻璃卡片，没有「数据概览 / 效率工具 / 最近动态」的层级分组。
- `.dash` 使用 `gap: 40px`，垂直间距过大，但区块内部内容密度又不低，形成「松一段、挤一段」的割裂感。

### 3. 网格排布不整齐
- 统计卡片：6 张卡固定 3 列，移动端 2 列，卡片大而重（`min-height:112px`、数值 `32px`、padding `24px`）。
- 最近动态：4 个面板却使用 3 列网格，导致第四张「继续阅读」单独一行，布局不齐。
- 云盘/密码库：`1fr 1fr` 双栏在内容量不等时高度不一致。

### 4. 视觉层次弱
- 所有卡片使用相同的玻璃底、边框、圆角、阴影，没有主次之分。
- 标题、副标题、数字、按钮、图例混在卡片里，缺少留白和层级。
- 快捷入口的「提示文字 + 箭头」放在右侧，视觉上容易和操作按钮混淆。

### 5. 响应式仍不够细
- 移动端统计卡 2 列仍偏挤；标题副标题在窄屏容易溢出。
- 最近动态、趋势图例、面板标题副标题没有统一的窄屏处理。

## 二、优化方向

### 方向 A：信息架构重组

#### A1. 去掉重复顶栏，统一为单一操作区
- 移除 `DashboardView` 内部 `.dash-head` 的「数据概览」标题行。
- 将「布局 / 刷新」保留为概览页主操作；「全量备份 / 数据导出 / 数据导入 / 查重」收进「更多」下拉（或放到 `JPageHeader` 的 `actions` 插槽）。
- 最终第一屏只保留：
  - `JPageHeader`：概览 + 副标题 + 返回/主题
  - 卡片区顶部一排轻量操作：布局、刷新、更多

#### A2. 增加区块分组与栏目标题
- 将概览内容分为 3 个语义组：
  1. **数据总览**：统计卡片 + 数据趋势
  2. **状态与效率**：今日待办 + 云盘占用 + 密码库健康
  3. **最近与快捷**：最近收藏/便签/文件/继续阅读 + 快捷入口
- 每组上方增加小标题（如「数据总览」「状态与效率」「最近动态」），弱化卡片视觉噪音，强化信息层级。
- 默认布局顺序保持用户可配置，但分组标题跟随组内第一个可见区块显示。

### 方向 B：网格与卡片重排

#### B1. 统计卡片
- 6 张卡使用 `repeat(auto-fit, minmax(150px, 1fr))`，桌面最多 6 列、常规 3 列、窄屏 2 列、极窄 1 列。
- 卡片尺寸收敛：
  - `min-height: 96px`
  - `padding: 16px 18px`
  - 图标 `38px`
  - 数值 `24px`（重要数字仍醒目，但不再占满整卡）
- 保留 `JCountUp` 和 hover 上浮，但 hover 位移从 `-2px` 改为更克制的 `-1px`。

#### B2. 最近动态
- 4 个面板改为：
  - 桌面 ≥1200px：`repeat(4, 1fr)`，一排四栏
  - 700–1199px：`repeat(2, 1fr)`，两排两栏
  - <700px：`1fr`
- 列表项间距从 `10px` 收窄到 `8px`，标题字号保持 `--fs-sm`，时间 `--fs-xs`。
- 四个面板高度尽量等高（`grid-auto-rows: 1fr`）。

#### B3. 中排状态卡
- 云盘占用 + 密码库健康保持双栏，但改为 `minmax(0, 1fr)` 且强制等高。
- 内容不足时用 `min-height` 对齐，避免一高一矮。

#### B4. 快捷入口
- 改为更清晰的「图标按钮组」，去掉右侧零散的「快捷入口 + 箭头」提示。
- 按钮统一圆角 pill、品牌色 hover，按钮间距 `8px`。

### 方向 C：视觉层级与统一

#### C1. 卡片体系
- 主统计卡使用现有 `JStatCard` 并微调；
- 普通信息面板统一 `.panel` 样式，但不再全部用强玻璃投影：
  - 主要面板：玻璃卡 + 轻投影
  - 次级面板：更浅的 `--glass-bg-trans` + 无投影或仅 `--shadow-1`
- 面板标题统一为「小图标 + 标题 + 右侧副信息」，副信息窄屏自动换行。

#### C2. 间距节奏
- `.dash` 的 `gap` 从 `40px` 调整为 `28px`。
- 区块内 `gap` 统一为 `16px`。
- 分组小标题与卡片间距：标题下 `12px`，组与组之间 `32px`。

#### C3. 空态/加载态
- 各面板空态统一使用 `JEmptyState` 或轻量 `panel-empty`，避免整页空态跳动。
- 概览加载仍用 `JSkeletonGrid`，错误态已用 `JErrorState`，保持不变。

### 方向 D：响应式与可访问性

#### D1. 移动端
- 统计卡：2 列 → 极窄 1 列（<420px）。
- 面板标题：副信息移到第二行或隐藏部分低频信息。
- 操作区：仅保留「布局 / 刷新」，其余进入「更多」底部抽屉或弹层。
- 快捷入口横向滚动或自动换行，保证点击区域 ≥ 40px。

#### D2. 暗色与对比度
- 检查玻璃卡片在暗色下的对比度，确保 `--text-2/--text-3` 可读。
- 趋势图例、磁盘条、健康警告在暗色下保持足够对比。

#### D3. 动效
- 统计卡保留 `JCountUp`；
- 分组标题/面板入场使用轻量 `fade-in-up`，不新增复杂动画；
- 遵循 `prefers-reduced-motion`。

## 三、实施顺序

1. **顶部收敛**（A1）：删除内部重复标题，操作收进「更多」。
2. **分组与间距**（A2/C2）：增加组标题，调整 `.dash` 与面板间距。
3. **网格重排**（B1/B2/B3/B4）：统计卡、最近动态、中排、快捷入口。
4. **视觉微调**（C1/C3）：卡片主次、空态、标题层级。
5. **响应式与可访问性**（D1/D2/D3）。
6. **验证**：`vue-tsc --noEmit` + `npm run build` + 手动视觉回归（1440 / 768 / 390）。
