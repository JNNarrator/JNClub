# JNClub 功能规划 · 2026-11（第二批 UI/UX 优化）

> 状态：✅ 第二批已实施（布局壳 / Home 拆件 / 移动端更多导航 / 交互与状态统一 / 响应式收尾已完成，`vue-tsc` 与 `npm run build` 通过）
> 前置：2026-10 第一批已完成并合入（Token 收敛 / Home 拆件 / 共享 UI 基件 / 骨架屏 / 动画 / 响应式）。
> 决策：本批仍不做新业务功能，聚焦「样式 UI 统一、界面布局收敛、操作逻辑 / 人机交互优化」；不新增后端表/接口/依赖，纯前端治理。
> 目标：在第一批「视觉 Token + 基件」基础上，把页面壳、操作入口、批量交互、移动端导航和可访问性统一到同一套设计语言，让日常使用更顺手、代码更易维护。

## 一、现状核实（基于当前代码）

### 已具备的地基
- `themes/tokens.ts`：语义色 / 模块色 / 玻璃体系 / 圆角 / 阴影 / 动效 token 已建立。
- `shared/components/ui/*`：JPageHeader / JSkeletonGrid / JSkeletonList / JFilterBar / JBatchBar / JStatCard / JEmptyState 已存在。
- 独立页（概览 / 待办 / 日历 / 订阅 / 回收站）已统一使用 `JPageHeader` 和骨架屏。
- 主界面 `AppHeader.vue`、`ModuleToolbar.vue`、`FolderPanel.vue` 已从 Home 拆出。
- 移动端已有底部 TabBar、目录抽屉、横向滚动 chips。

### 仍存在的问题（规划依据）

1. **页面壳高度重复**  
   `OverviewLayout / TodoLayout / CalendarLayout / FeedsLayout / RecycleLayout` 的 `.xxx-page + .xxx-body` 结构几乎相同，都是 `padding: 12px 24px 0` + 玻璃面板 + `max-width: 1560px`。后续调间距/最大宽度需改 5 个文件。

2. **Home.vue 仍偏大（1150 行）**  
   虽然已拆出顶栏/工具栏，但收藏新建/编辑弹窗、批量移动/打标签弹窗、移动端目录抽屉仍堆在 Home 内，继续新增功能容易互相影响。

3. **两套页头并存**  
   - 主界面：`AppHeader.vue`（面包屑 + 搜索/多选/视图/刷新/主题/用户）
   - 独立页：`JPageHeader.vue`（标题 + 刷新/主题/返回）
   两者视觉和结构不一致，移动端 AppHeader 右侧操作过密。

4. **移动端导航有缺口**  
   `MOBILE_KEYS` 不包含 `music` 和 `extension`，底部 Tab 只能横向滚动，没有「更多」入口；隐藏导航项后也没有统一入口找回。

5. **操作入口与批量交互不统一**  
   - 收藏卡片/列表、便签卡片/列表、云盘、密码库各有各的批量条/右键菜单/行内操作，未统一复用 `JBatchBar` 和同一套菜单项。
   - 部分列表行/卡片是 `div + @click`，缺少键盘可达性；hover 才显示 `...`，触屏上不够友好。
   - 空态/错误态未完全统一：待办、订阅、日历仍混用 `NEmpty`；部分页面缺少错误重试。

6. **响应式仍有缺口**  
   - RSS 阅读器三栏在窄屏仍是三栏或压缩，缺少移动端阅读态。
   - 日历 / 待办 / 云盘工具栏在窄屏容易溢出。
   - safe-area / 键盘弹起 / 底部批量条遮挡等问题未系统处理。

7. **样式硬编码残留**  
   `grep` 显示仍约 50 处 hex/rgba 字面量，多数有合理理由（粒子、光标、SVG 描边、favicon 白底），但仍有 `FeedsView #fff`、`SnapshotModal #fff`、`DiskView #111/#000` 等可收敛或注释归类。

## 二、方向与任务拆解

### 方向 A：页面布局壳统一（界面布局优化）

#### A1. 新增共享页面壳 `JPageShell`
- 新建 `src/shared/layout/JPageShell.vue`，收敛：
  - 外距 `padding: var(--layout-page-gutter, 12px 24px 0)`
  - 内体玻璃面板 `.glass-panel`
  - `max-width: var(--layout-content-max, 1440px)`
  - 移动端统一间距
- `Overview / Todo / Calendar / Feeds / Recycle` 五个 Layout 全部改为：
  ```vue
  <JPageShell>
    <JPageHeader ... />
    <slot />
  </JPageShell>
  ```
  删除各自重复的 `.overview-body / .todo-body / .calendar-body / .feeds-body / .recycle-body` 样式。

#### A2. 新增布局 Token
- `themes/tokens.ts` 增加：
  - `layoutContentMax`（默认 `1440px` 或保持 `1560px`，二选一后全项目统一）
  - `layoutPageGutter`
  - `layoutPanelPadding`
  - `headerHeight`
  - `tabbarHeight`
- 输出 CSS 变量：`--layout-content-max / --layout-page-gutter / --layout-panel-padding / --header-height / --tabbar-height`。
- 替换 Home / Dashboard / 各 Layout 中的魔法 `1560px / 24px / 20px / 60px / 56px`。

#### A3. Home 主体继续拆件
- 抽出 `modules/bookmark/components/BookmarkFormModal.vue`：收藏新建/编辑表单、URL 预览、TagPicker。
- 抽出 `modules/bookmark/components/BatchActionModals.vue`：批量移动 / 批量打标签弹窗。
- 抽出 `modules/bookmark/components/DirectoryDrawer.vue`：移动端目录抽屉。
- 抽出 `composables/useBatchActions.ts`：多选状态、全选、移动/打标签/删除逻辑。
- 目标：`Home.vue` 从 1150 行降到约 700 行以内，只保留编排与数据流。

### 方向 B：导航与页头统一（样式 UI + 操作逻辑）

#### B1. 统一页头体系
- 让 `AppHeader.vue` 与 `JPageHeader.vue` 共用同一套按钮/间距/字号样式，或者让 AppHeader 内部使用 `JPageHeader` 的样式 token。
- 主界面顶栏右侧操作分组：
  - 常用：搜索、视图切换、刷新
  - 低频：多选、主题、用户
  - 移动端：搜索 / 目录保留，多选/视图/主题/用户收进「更多」弹出层或底部抽屉。
- 增加顶部栏在窄屏的可横向滚动或自动收纳，避免 5+ 个圆钮挤压。

#### B2. 移动端底部导航升级
- `MobileTabBar.vue` 增加「更多」Tab，点击弹出 `ActionSheet` 或抽屉：
  - 展示当前未在底部显示的合法导航项（含 `music`、`extension`、被用户隐藏项）
  - 支持「显示/隐藏」开关，入口从「更多」找回隐藏导航。
- `MOBILE_KEYS` 保持精简，但不再让任何导航项“永远不可达”。

#### B3. 侧栏底部入口收纳
- 将「光标样式 / 背景特效 / 编辑导航」三个小按钮收纳为一个「个性化」按钮 + 弹出菜单，减少侧栏底部视觉噪音。

### 方向 C：操作逻辑 / 人机交互优化

#### C1. 卡片与列表的键盘可达性
- 可点击卡片/行从 `div @click` 改为语义化结构：
  - 外层用 `<article>` 或 `<div role="link" tabindex="0">`，支持 `Enter` / `Space` 打开。
  - 内部真实链接、按钮保持独立可聚焦，避免嵌套可点击元素。
  - 统一 `:focus-visible` 样式（现有全局已有，补充到卡片/列表）。
- 收藏/便签/云盘/密码库统一：
  - 右键菜单 + 可见 `...` 按钮并存（触屏始终可见，桌面 hover 才高亮）。
  - 菜单项顺序统一：打开 / 阅读 / 稍后读 / 快照 / 移动 / 分享 / 编辑 / 删除。

#### C2. 批量操作统一
- 所有模块的批量条统一使用 `JBatchBar`：
  - 收藏/便签：已有，补齐「全选当前目录」「已选计数动画」。
  - 云盘：现有内嵌批量条改为 `JBatchBar`，支持全选/移动/下载/删除/取消。
  - 密码库：增加批量删除（如后端允许）或至少统一视觉。
- 移动端批量条固定底部 safe-area，与 TabBar 同时出现时上移或替换 TabBar。

#### C3. 弹窗交互规范
- 统一：
  - 打开弹窗自动聚焦第一个输入框。
  - `Enter` 提交、`Esc` 关闭。
  - 破坏性操作（删除/重置/清空）二次确认。
  - 提交中按钮 loading，成功后轻提示，失败展示错误并可重试。
- 新建/编辑弹窗统一用 `glass-card--modal` 与全局玻璃覆盖。

#### C4. 搜索 / 命令面板体验
- `SearchDrawer` 增加：
  - 键盘上下选择、Enter 跳转、Esc 关闭。
  - 空结果 / 加载中 / 错误重试状态。
  - 跳转后能正确落到目标目录并高亮。
- 将 `HelpDrawer` 与搜索/命令面板入口在移动端补充可见按钮，不只依赖快捷键。

#### C5. 空态 / 错误态 / 加载态统一
- 全项目用 `JEmptyState` 替换散落的 `NEmpty`（待办、日历空月、订阅、回收站）。
- 新增 `JErrorState`（或扩展 `JEmptyState` 支持 error 模式）：
  - 统一错误插画 + 错误原因 + 「重试」按钮。
  - 接入 Dashboard / Todo / Calendar / Feeds / Recycle / Home 的请求失败分支。
- 局部操作保留行级 loading / 按钮 loading，不整页转圈。

### 方向 D：视觉样式与响应式收尾

#### D1. 样式 Token 清理
- 复核剩余 hex/rgba：
  - 合理保留：粒子/光标/第三方 favicon 白底/SVG 描边。
  - 收敛对象：`SnapshotModal #fff`、`DiskView #111/#000`、`FeedsView #fff`、`NoteEditor #fff` 等改为 token 或注释说明。
- 补充文件类型色 / 状态徽标色 / 阅读进度色到 token，替换散落值。
- 检查亮暗双模式下玻璃透明度、对比度、滚动条、选中态。

#### D2. 响应式细化
- RSS 阅读器：
  - 窄屏（<1024px）三栏 → 两栏（订阅源列表 + 内容，或列表 + 阅读）。
  - 手机（<768px）→ 单栏：列表与阅读用抽屉/独立视图切换。
- 日历：
  - 窄屏单元格压缩；星期表头固定；待办拖拽保留触屏降级（点击单元格快速新建）。
- 待办 / 云盘 / 密码库：
  - 工具栏允许横向滚动或收纳到「更多」。
  - 底部批量条、FAB、上传条处理 safe-area。
- Home：
  - 目录抽屉宽度、chips 横向滚动、卡片密度、空态间距统一。

## 三、实施顺序

1. **布局壳收敛（A1/A2）**：新增 `JPageShell` + 布局 Token，替换 5 个独立 Layout 与 Home 的重复面板样式。
2. **Home 拆件（A3）**：抽出收藏表单 / 批量弹窗 / 目录抽屉 / 批量 composable，让 Home 只做编排。
3. **导航与页头（B1/B2/B3）**：统一 AppHeader 与 JPageHeader，移动端「更多」底部导航。
4. **交互统一（C1/C2/C3）**：卡片/列表键盘可达、右键菜单统一、批量条统一、弹窗规范。
5. **状态统一（C4/C5）**：搜索/命令面板增强，空态/错误态/加载态全量替换。
6. **视觉与响应式收尾（D1/D2）**：Token 清理、RSS/日历/待办/云盘移动端适配。
7. **全量验证**：`vue-tsc --noEmit` + `npm run build` + 手动视觉回归清单。

## 四、验收标准

- [ ] 5 个独立 Layout 不再各自重复 `.page/.body` 样式，统一由 `JPageShell` 承载。
- [ ] `Home.vue` 明显瘦身（目标 ≤ 800 行），新建/编辑/批量/目录抽屉均为独立文件。
- [ ] `AppHeader` 与 `JPageHeader` 视觉同一套；移动端顶栏不再挤压。
- [ ] 移动端可通过「更多」进入音乐 / 下载中心，并可找回被隐藏导航项。
- [ ] 收藏/便签/云盘/密码库均可用键盘打开、聚焦可见；右键菜单与可见 `...` 并存。
- [ ] 所有模块批量条统一使用 `JBatchBar`，移动端 safe-area 正确。
- [ ] 待办/日历/订阅/回收站空态与错误态统一为 `JEmptyState / JErrorState`，可重试。
- [ ] RSS 在手机端可正常阅读，不再三栏硬挤。
- [ ] `grep` 抽查：业务组件魔法色已收敛，剩余均注释归类。
- [ ] 后端不新增表/接口/依赖；`mvn compile` 无变化，`vue-tsc --noEmit` 通过，`npm run build` 通过。
